The root `package.json` declares npm workspaces for `client/` (React/Vite SPA) and `server/` (Fastify backend), exposing unified scripts (`dev`, `build`, `migrate`, `seed`) that delegate to each workspace. Development runs via `docker-compose.yml`, which orchestrates three services — PostgreSQL, the Fastify server (built from `server/Dockerfile`), and the Vite dev server — with the client proxying `/api` requests to the server on port 4000. Production deploys the SPA as a static site built by the root `Dockerfile` (two-stage build over the whole workspace) and served by the zero-dependency `serve.cjs`, which serves `client/dist` and reverse-proxies `/api/*` to the separate Dokploy backend service at `API_UPSTREAM`. The two child modules communicate exclusively over HTTP: the client calls the server's REST endpoints through the same-origin `/api` proxy, while shared concerns (PostgreSQL schema via migrations, upload storage under `.yz-uploads`, environment-driven config like `DATABASE_URL`, `CORS_ORIGINS`, `TRUST_HEADER_AUTH`) are wired per-service rather than shared at the root.
