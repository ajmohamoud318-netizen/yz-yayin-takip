Web Push requires `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` (generated via `npx web-push generate-vapid-keys`); without them the service disables itself and all push functions become no-ops while the in-app bell still works. Background maintenance is started via `startNotificationMaintenance()` and stopped via `stopNotificationMaintenance()`. Tests use Node's built-in `node:test` runner against a fake pg client — no real DB required for the delivery contract tests.
