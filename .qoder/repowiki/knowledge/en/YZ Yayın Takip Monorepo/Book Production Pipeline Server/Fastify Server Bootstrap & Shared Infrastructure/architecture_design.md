The module is organized around four concerns that every route depends on:
- Entry point (`src/index.js`): builds a Fastify 5 app with `@fastify/helmet`, `@fastify/cookie`, `@fastify/multipart`, CORS (origin allowlist from config), a global error handler that maps domain `HttpError`s to `{error, code}` JSON, registers all route modules under `/api`, mounts `/api/health`, runs optional migrations/seeding, starts background notification maintenance, and handles graceful shutdown by stopping timers, closing Fastify, and ending the pg pool.
- Configuration (`src/config.js`): single source of truth read from `process.env` (Dokploy / `.env`) with typed helpers `intEnv`/`boolEnv`; exposes host/port, database URL, pool size, CORS origins, session cookie settings, SMTP, VAPID push keys, Redis URL, and rate-limit store selection.
- Database layer (`src/db/pool.js`): lazily instantiated `pg.Pool` singleton accessed via `getPool()`, plus a `withTx(fn)` helper that wraps calls in BEGIN/COMMIT/ROLLBACK and attaches an `afterCommit(cb)` hook executed via `setImmediate` after commit so side effects never run inside the transaction. A `__setPoolForTests` seam lets tests inject a fake pool; `closePool()` ends it on shutdown.
- Validation surface (`src/schemas/index.js`): centralized AJV schemas for every state-changing route body/params/querystring, using shared fragments (`userId`, `projectId`, `password`, `stage`, `rejectTarget`, `subtaskInput`, `linksList`, `productComponents`) and `additionalProperties: false` to reject unknown fields at the framework level before handlers run.
- Rate limiting (`src/middleware/rate-limit.js`): factory returning a Fastify preHandler that enforces sliding-window limits per arbitrary request-derived keys; backends are selected at runtime via `config.rateLimit.store` — an in-process `Map` (default) or a lazy-loaded `ioredis` sorted set, with automatic fallback to memory on Redis failure.
- Packaging (`Dockerfile`, `docker-entrypoint.sh`, `.dockerignore`, `package.json`): two-stage Alpine build installing production-only deps, exposing port 4000, running a healthcheck against `/api/health`, and an entrypoint that creates/chowns the avatar upload directory then drops to the unprivileged `node` user via `gosu` before exec'ing `node src/index.js` so SIGTERM reaches Fastify directly for clean shutdown.
