`npm run dev` uses `node --watch src/index.js`; `npm run migrate`/`seed` invoke separate scripts; production runs via `node src/index.js` (not `npm start`) so PID 1 receives signals. Docker image is built with `--build-arg GIT_COMMIT=$(git rev-parse HEAD)` so `GET /api/health` reports the live commit. The container entrypoint requires `AVATAR_DIR` (defaults to `/app/.yz-uploads/avatars`) and expects Dokploy-managed volumes owned by UID/GID 1000.
