The server root bootstraps a single Fastify instance via `src/index.js` and `src/config.js`, which registers every domain's routes (`routes/*.js`) and middleware (`middleware/*.js`). Each domain layer follows the same three-tier split: route handlers in `server/src/routes/` delegate to pure service functions in `server/src/services/`, which persist state through the shared PostgreSQL pool exposed by `src/db/pool.js`. Domain transition logic is isolated in `src/domain/` (order transitions, pipeline stages, progress tracking) so routes stay thin. Cross-cutting concerns — JSON schema validation (`schemas/index.js`), authentication/rate-limiting middleware, file uploads under `server/uploads/`, and DB migrations under `db/migrations/` — are consumed uniformly by every domain. Docker packaging (`Dockerfile`, `docker-entrypoint.sh`) runs the same entrypoint for both development and production.
