Single Remotion project rooted at `src/Root.jsx`, which registers one composition (`YZLogoReveal`, 120 frames at 30 fps) whose component is `LogoReveal`. `LogoReveal.jsx` composes the primary brand-mark + wordmark animation using spring-driven motion, clip-path wipe, divider, tagline, and floating background particles. `LogoAnimation.jsx` provides an alternative dark-themed variant driven by frame-indexed `interpolate` calls over inline SVG `<path>` data arrays for each letter of 'YÜKSELEN' and 'ZEKA', plus a vertical divider, shine-sweep gradient rect, and fade-out overlay. Both compositions are pure React components built from Remotion primitives (`AbsoluteFill`, `useCurrentFrame`, `useVideoConfig`, `interpolate`, `spring`, `Img`, `staticFile`) with no external state or side effects; assets live in `public/` as `yz_blacklogo.svg` and `yz_whitelogo.svg`. The module is configured via `package.json` scripts (`studio` for preview, `render` for MP4 output) and declares `remotion` entry point to `./src/Root.jsx`.
