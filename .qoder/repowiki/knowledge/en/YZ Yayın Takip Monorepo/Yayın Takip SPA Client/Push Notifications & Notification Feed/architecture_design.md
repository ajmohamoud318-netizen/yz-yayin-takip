Three cooperating pieces form the push/notification layer:
- `useNotifications.jsx` exposes a `NotificationsProvider` + `useNotifications()` context that owns a single polling loop (`POLL_MS = 15000`) against `api.listNotifications`, keeping local state for items, unread count, unseen badge, and loading. It also exposes `markRead`, `markAllRead`, and `markSeen` which optimistically update local state before persisting via `api.markNotificationRead` / `markAllNotificationsRead` / `markNotificationsSeen`; failures are reconciled on the next poll. The effect is keyed on `user.id` so switching accounts resets state.
- `usePushNotifications.js` manages the full Web Push subscription lifecycle into one `status` string (`unsupported`/`desktop`/`needs-install`/`disabled`/`denied`/`default`/`subscribed`). It detects platform capabilities (`isIOS`, `isMobileDevice`, `isStandalone`), gates setup behind user gestures, handles VAPID key rotation by comparing `applicationServerKey`, and synchronises browser subscriptions with the server via `api.getPushPublicKey`, `savePushSubscription`, `deletePushSubscription`, and `sendTestPush`. A shared `statusPeers` Set keeps multiple hook instances in sync when both the setup sheet and bell dropdown mount it.
- `PushBridge.jsx` is an invisible root component that connects the service worker to the SPA: it listens for `notificationclick` postMessages from `sw.js`, drains a pending target parked in IndexedDB via `takePendingPushTarget` using a decaying retry schedule (`DRAIN_RETRY_MS = [0,150,400,900,1600]`) to cover resume races, marks the tapped notification read, refetches the feed, and navigates via React Router. It also registers visibility/focus/pageshow listeners plus `useOnResume` to refresh the feed on foreground transitions.
Dependency direction is one-way: `PushBridge` consumes `useNotifications` and `useAuth`; `usePushNotifications` consumes `useAuth` and `@/api`; nothing in this module imports the other two hooks directly, keeping the feed and push subscription concerns decoupled while both converge on the same API surface.
