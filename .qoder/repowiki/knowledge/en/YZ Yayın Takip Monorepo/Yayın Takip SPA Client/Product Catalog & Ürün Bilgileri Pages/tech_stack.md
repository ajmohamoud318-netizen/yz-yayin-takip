React functional components with hooks (`useState`, `useEffect`, `useMemo`); UI built on shadcn-style primitives (`Card`, `Badge`, `Button`, `Skeleton`) and lucide-react icons; toast notifications via `sonner`; cross-tab sync via the `storage` event; persistent state split between an in-memory `Map`, `localStorage` (key `yz_product_info_overrides_v1`), and the server `product_info` table accessed through `@/api`.
