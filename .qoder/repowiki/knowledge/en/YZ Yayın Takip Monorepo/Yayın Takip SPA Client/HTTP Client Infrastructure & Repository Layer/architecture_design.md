Two-layer structure inside `client/src/infrastructure`:
- `http/client.js` builds a single configured Axios instance (`httpClient`) with a base URL resolved from `VITE_API_BASE_URL` (defaulting to same-origin `/api`), a global 20 s timeout, `withCredentials: true`, an `X-User-Id` request interceptor sourced from a module-level mirror plus `localStorage` fallback, and a response interceptor that normalizes errors (adding `status`, `offline`, `code`, `cause`), translates network failures into Turkish messages, and on 401 tears down the session and redirects to `/login`.
- `http/repositories/*.repository.js` each export a factory (e.g. `createHttpAuthRepository`) returning a plain object of async methods that call `httpClient` against specific API paths; one repository per domain (auth, demo, handover, meeting, notification, order, product-info, project, push, subtask, target-project-idea, user, work-log).
- `shared/errors.js` defines typed error constructors (`notFound`, `badRequest`, `unauthorized`, `forbidden`, `conflict`) that attach a numeric `status` so the axios response interceptor can surface them unchanged to the UI.
Dependency direction is strictly inward: repositories depend only on `../client.js` and `../../shared/errors.js`; nothing in this module imports application features, keeping it a pure infrastructure boundary.
