The module centers on a React Context (`AuthContext` in `useAuth.js`) that owns the global user session. `AuthProvider` bootstraps state by reading a persisted JSON blob from `localStorage` under key `yz_auth_v1`, then calls `GET /auth/me` via the shared `api` client to verify an httpOnly cookie session; it retries up to `OFFLINE_RETRIES` times with exponential backoff and caps total wait at `BOOTSTRAP_MAX_MS` so the UI never hangs indefinitely. On success it refreshes the cached user while preserving the original `expires_at` stamp for '30 gün hatırla' (remember-me) sessions. The context exposes `login`, `loginAsUser`, `logout`, `updateUser`, plus flags `user`, `loading`, `bootstrapping`, `sessionUnverified`, and `isAuthenticated`. `Login.jsx` is a form page that consumes `useAuth` to submit credentials, optionally persisting the email/remember preference in separate localStorage keys (`yz_remember_pref`, `yz_remember_email`), and redirects authenticated users away from the login route. `ForgotPassword.jsx` is a standalone page that calls `POST /auth/forgot-password` directly via `api` and shows a success state regardless of whether the email exists (server always returns 200). Dependency direction: pages depend on the hook; the hook depends only on the shared `api` client and a `useOnResume` foreground-retry hook — no reverse imports.
